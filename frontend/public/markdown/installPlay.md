## **PC Platforms**

### **Windows**

On Windows, installing Vedora is easy.
1. Install Vedora Player
    * Go to any game on the Vedora website
    * Click the **Play** button
    * Click the **Download and Install Vedora** button on the modal that will appear
    * Your browser may say the download is dangerous. This is called a false-positive, due to the Vedora launcher not being signed. **Click on the "Antivirus detects Vedora as a trojan" article for a deeper explanation and a solution.**
2. Launch the player via any modern browser (Chromium-based, Firefox)
    * Go to any game on the Vedora website
    * Click the **Play** button
    * A secondary pop-up may appear asking you to select a program. Select Vedora and confirm. If you select to remember your choice, you will not need to perform this action in the future

### **macOS**

Vedora currently does not support macOS.

### **Linux**

While it is **possible** to get Vedora working on Linux using Wine, it is **not supported** and we will not help you troubleshoot any issues you encounter while trying this. (though you can ask around in our Discord!)

*Do note that the 2021 client is guaranteed to not work on Linux, for now. This is due to our anti-cheat not supporting it yet.*

## **Mobile Platforms**

Visit the download page for mobile Vedora versions [by clicking here](/download2)

Vedora runs 2021 games only, so you should download the 2021 client for your platform.

### **Android**

Vedora on Android currently only supports one version, 2021.

To install Vedora 2021, you must download an APK file, which is equivalent to an EXE or an MSI file on Windows. This will automatically download the Vedora 2021 app for you. 
However, this **will overwrite the official Roblox app** unless you clone it yourself and change the package name.

We are working on a better solution for mobile, including improving 2021 support.

## **Vedora Studio**

All studios currently only support Windows 7 and above. The only available studio version is 2021.

As of right now, there is no Studio Bootstrapper, meaning you'll have to manually download each studio and extract them to wherever you'd like. This will change in the future.

Vedora Studio downloads can be [found here.](/download)

### How to Download and Install Vedora Studio

1. Choose your Studio version and download
   * Go to the **[download page for Vedora Studio](/download)**
   * Choose which Studio version you would like to download
   * Click **"Download Studio (TODO: or whatever the button will be called eventually)"** and let the download finish
2. Extract your Studio to wherever you'd like
   * Open the compressed folder (.zip) in your archive tool of preference (7z, WinRAR, etc.)
   * Drag the folder containing Studio to wherever you'd like on your PC
3. Open your Studio and login
   * If you have two-factor authentication, you must put your 2FA code in the username field in this format: "Zyth|003621" (replace Zyth with your username and 003621 with your 2FA code)
